# SHLO3 AI — مشروع تطبيق أندرويد

هذا مشروع Android Studio حقيقي كبداية قابلة للبناء، وليس صورة واجهة فقط. يحتوي على:
- تطبيق Android بلغة Kotlin.
- محادثة عربية/عراقية مع خادم API.
- زر لتوليد الصور عبر الخادم.
- خادم Node.js يحفظ مفتاح API خارج التطبيق.

## مهم قبل التشغيل
المشروع لا يتضمن مفتاح API مدفوعاً أو مجانياً جاهزاً. يلزمك إعداد مفتاح من مزوّد نموذج ذكاء اصطناعي، ثم وضعه في ملف `.env` على الخادم. لا تضع المفتاح داخل APK لأن أي شخص يستطيع استخراجه.

## تشغيل الخادم
1. ثبّت Node.js على كمبيوتر أو استضافة تدعم Node.
2. افتح مجلد `server`.
3. انسخ `.env.example` إلى `.env` واكتب مفتاح API.
4. نفّذ:
   ```bash
   npm install
   npm start
   ```
5. اجعل الخادم متاحاً عبر HTTPS، ثم عدّل `BASE_URL` في `app/src/main/java/com/shlo3/ai/MainActivity.kt` إلى عنوان الخادم.

الخادم يستخدم واجهة OpenAI-compatible. إذا كان مزوّدك يستخدم مسارات أو نماذج مختلفة، عدّل `server/index.js`.

## بناء APK
1. افتح مجلد المشروع في Android Studio.
2. انتظر مزامنة Gradle.
3. من القائمة اختر **Build > Build APK(s)**.
4. ستجد الملف عادةً داخل `app/build/outputs/apk/debug/`.

## ملاحظات
- لا تستخدم عنوان `10.0.2.2` إلا للاختبار على محاكي Android متصل بخادم يعمل على نفس الكمبيوتر.
- لا تضع أسرار API في التطبيق.
- هذا مشروع بداية عملي؛ يلزم إعداد الخادم ومفتاح API قبل أن تعمل إجابات الذكاء الاصطناعي وتوليد الصور.
